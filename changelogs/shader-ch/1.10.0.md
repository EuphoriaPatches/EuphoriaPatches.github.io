### Changes

- Updated to Complementary Shaders r5.8 [YOUTUBE SHOWCASE](https://www.youtube.com/watch?v=xu8--_-_qhQ)
- Added a Black Hole to the End: Comes with fully customizable parameters so you can tweak it to your liking. From size to amount of swirls and pixelation.
- Added an End Nebula with many many options that can be tweaked. Based on the one from Supplemental Patches, thanks to [@lemon41625](https://github.com/jedlimlx)
- Added a new "Improved LabPBR" option: reflections now behave as the resource pack creator intended! Materials are now as reflective as they should be, hardcoded metals are now supported, including albedo tinting and correct specular F0 handling. Refractions are now also supported with LabPBR. Translucent objects will correctly refract/distort what is behind them! I also added LabPBR porosity support and LabPBR texture ambient occlusion support! This makes Euphoria Patches with the Improved LabPBR option enabled mostly LabPBR feature complete!
- Added [WindLink](https://modrinth.com/mod/windlink) support, it syncs foliage, weather, particles and more to a single realistic wind system.
- Euphoria Patches Seasons will be now in sync with Serene Seasons, Fabric Seasons and Ecliptic Seasons when using the Euphoria Patcher mod
- Automatic `doDaylightCycle` / `advance_time` Detection: With Euphoria Patcher installed, the shader automatically detects said gamerule, allowing clouds, caustics, aurorae, and other time-based animations to continue even when it's false. Works on Forge, NeoForge, and Fabric (Tested: 1.18–26.2). A setting is available to restore the previous no-animation behavior.
- Smooth Time Changes: Changing time now smoothly interpolates between the old and new time instead of instantly jumping. This even includes seasons!
- Added support for the `dragon_death_rays` entity ID I added via the Euphoria Patcher mod. Now the dragon death beam detection is 100% always reliable. This took around 8h or more to get working... Biggest pain.
- Made the `dragon_death_rays` ID also work with Angelica
- Mixined into Oculus to add the dragon healing beam entity ID support there as well, meaning you can now see the healing beam from Euphoria Patches with Oculus as well if you enabled the option!
- Improved Overworld Beams, make it close to the new rewritten end beam code from Complementary 5.8
- Made Overworld Beams work with LOD mods
- Improve how clouds look in front of the sun with pixelated unbound clouds
- Added the panini projection as a post effect
- Added a way to disable photonics handheld lighting
- Allow higher than 1.0 cloud opacity to make them more opaque
- Further improve custom sky support
- Add new block IDs to support constant emissive blocks
- Double the Blood Moon max amount
- Added a Colored Light Fog Cave Intensity setting
- Added more values to the End Sun Angle slider.
- Added End crystal Vortex pixelization
- The end flashes should now work on supported Angelica versions
- Improved End rod Screenspace colored lighting in End
- Added a warning message when NeOculus is installed
- Improved dismissible error messages by displaying a countdown timer indicating when the message can be closed.
- Improved the N-Polygon lens flare shape. They look much fuller than before and just objectively better.
- Added a Blurred Reflections setting: change the blurriness of reflections, if you disable blurred reflections, it's recommended to use FULL resolution reflections
- Added a Reflection Responsiveness setting: Makes reflections react faster to movement, reducing the ghosting/trailing effect they can have, higher values might make reflection noise more apparent though
- Added more modded blocks to the [properties files](https://github.com/EuphoriaPatches/propertiesFiles) thanks to the contributors <3
- Updated [translations](https://www.euphoriapatches.com/lang) thanks to the contributors <3
- Moved the translations to Crowdin! https://crowdin.com/project/euphoriapatchesshader
