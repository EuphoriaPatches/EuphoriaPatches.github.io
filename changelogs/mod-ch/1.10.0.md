### Changes

- EP mod now supports uniform uploading. Works on Iris/Oculus and even OptiFine! On all Minecraft versions you would want (Optifine only tested in 1.21 but Optifine code is ancient, doubt it got changed much)
- Added an `isTimeAdvancing` uniform which returns the value of the gamerule `doDayLightCycle`/`advance_time`
- Add milliseconds uniforms `euphoriaPatchesCurrentDayMillis` which tells the current millisecond since UTC midnight, resets again at midnight. `euphoriaPatchesCurrentDayMillisLocal` also exists which is the same thing but uses local midnight as a reference and not UTC.
- Add screenshot steganography: embed shader settings in PNG pixels via LSB, totally invisible, survives discord PNG uploads as there is no compression there. Just drag and drop the screenshot into the game within the iris GUI and the settings from the screenshot are applied. Every screenshot is at the same time a backup of your settings now.
- Intercepts file drops on the shader selection list to apply shader settings to the current shader. Default iris behavior is only within the shader option screen, not the selection one and this was annoying.
- Added support for the `dragon_death_rays` entity ID via the Euphoria Patcher mod. Now the dragon death beam detection is 100% always reliable.
- Added `end_crystal_beam` support on Forge 1.20.1 via the EP mod. Oculus did not have this hardcoded entity ID supported.
- Added support for the new set screen method in 26.2 used for some mod feature
- Added Caelum detection to get that info on the shader side for better compatibility.
- Added scrollable shader name text to fabric 1.20.1 (before it was only on forge)
- potato
- Optimized pngs thanks to [@Eclipse-Sol](https://github.com/Eclipse-Sol)
- Added partial wildcard `*` support to Iris's `dimension.properties` parsing. We are now doing `dimension.world-1=the_nether *nether*` so if anyone has any other dimension which has nether in the name, it will be assigned to the nether dimension automatically now. This was a very common issue of world with the multiverse plugin. Now as long as these world contain the `nether` or `end` in the dimension name, they will be assigned correctly.
- Made it work on 26.3 after the SDL3 change (not everything for 26.3 is tested, likely more things need fixing but can't check as there is no iris for 26.3 yet)
- Further improved user-facing error messages
- Add NeOculus detection to warn users not to use it because of its buggy nature
- Add seasons mod support. The Euphoria Patches shader seasons feature now perfectly syncs with seasons from the Fabric Seasons, Serene Seasons and Ecliptic Seasons mods when one of them is installed. No need to manually sync it anymore.
- Added a Stellar View Define for better compatibility.
- Added a donation prompt which only appears once and then never again on that instance and only to active core users of the shader.
- Improve the handling of shader settings conversion by a lot. Now we actually use iris mixins to convert shader settings during the import process, and not wait until the user reloads the shader like we did before. This ensures that settings which got renamed can now be converted as well which was not the case before as Iris strips nonexistent settings from the file.
- Added translation support via Crowdin: https://www.euphoriapatches.com/lang
- Much code cleanup


### Fixes

- Fixed at_midBlock precision issues at high coords on all iris/oculus versions which caused colored lighting to break.
- Fixed an exception during shutdown and catch it now, 26.2 changed shutdown behavior and this was then made noticeable
