### Changes

- Improve dimension load time switching **significantly** by caching shaders per dimension. Amount of dimensions cached can be tweaked in the config file. The faster load times aren't free, they cost RAM.
- Improved the settings updater when the user is installing both shader styles
- Mark screenshot files as such via a wrapper, compatibility for mods which save screenshots in a different directory. Now our settings embedding also works with such mods an example being https://modrinth.com/mod/screenshot-manager-enhanced. It only works with those who end up using the `NativeImage.writeToFile` approach to save it to disk. mods which use `Files.write` can't be made easily compatible.
- Improve sodium console logging to also work on 1.20.1 and overall clean it up
- Made the sodium console messages a bit cleaner by only showing the `Euphoria Patcher: ` header on the first message.
- Improve the timing when we automatically copy a link to clipboard when an error message with a link pops up
- Updated translations via Crowdin: https://www.euphoriapatches.com/lang


### Fixes

- Fix my dimensions.properties wildcard feature breaking the iris catch-all `*`. This broke Shaders like Mellow, sorry :(
- Fixed multiple issues which prevented a random person to clone the repo and just build it, they often than not encountered build errors. Now everyone should be able to build the mod from source without any compile errors popping up.
- Fix fabric yarn copy to clipboard not working
- Fixed a lot of files being generated in `.minecraft\.mixin.out` by removing all `@Debug` annotations. It was not needed at all, back then thought it was, but `-Dmixin.debug.export=true` does exactly what I needed XD
